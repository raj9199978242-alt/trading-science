# Trading Science Website

Static website for **Trading Science**, a one-to-one stock market learning platform led by **Kundan Kumar**. The site is built for course SEO, city landing pages, fast loading, mobile-first browsing, and WhatsApp booking.

## Pages

- Home
- About Trading Science / Founder
- Courses
- Blog
- City landing pages
- Contact / WhatsApp booking

## Features

- Trading Science logo and brand assets
- Homepage based on the approved visual layout
- Course detail pages with beginner, intermediate, and advanced topics
- Founder pages using Kundan Kumar's image and profile
- WhatsApp booking via `6203560944`
- Contact page without physical address or unrelated legacy imagery
- SEO city landing pages for major Indian cities
- Blog architecture for natural organic ranking
- `robots.txt`, `sitemap.xml`, metadata, and JSON-LD schema
- Educational compliance copy with no profit guarantees or investment advice
